# 🐍 Exercícios Python

Repositório com os exercícios que venho desenvolvendo durante meu aprendizado de Python, através do curso **Curso em Vídeo**. Aqui documento minha evolução, do zero até tópicos mais avançados.

---

## 📁 Organização

Os exercícios estão organizados por "mundos", seguindo a estrutura do curso:

```
exercicios-python/
├── mundo-1/    → Fundamentos: variáveis, tipos, operadores, entrada e saída
├── mundo-2/    → Estruturas de controle: condicionais (if/else/match), listas, strings, estruturas de repetição: for, while
├── mundo-3/    → (em breve)
└── mundo-4/    → (em breve)
```

---

## 🎯 Sobre este repositório

Cada arquivo representa a resolução de um exercício proposto no curso. Sempre que possível, busco:

- Escrever um código limpo e organizado
- Entender o porquê de cada solução, não apenas fazer funcionar
- Revisar e melhorar exercícios anteriores conforme aprendo novos conceitos
